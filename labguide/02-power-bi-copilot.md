# Exercise 02: Analyze Campaign Performance with Copilot for Power BI

### Estimated Duration: 15 Minutes

## 📘 Scenario

With Zava's and Litware's data in OneLake, Wendy, Zava's data analyst, needs to produce Power BI reports for stakeholders across the company. She wants insights fast, without waiting on IT or writing code.

## 📖 Overview

In this exercise, you act as Wendy. You create a semantic model on the website bounce-rate table, turn on Q&A, and then use Copilot for Power BI to explore the data, generate a report page, get recommendations, and write an executive summary with the Narrative visual.

## 🎯 Objectives

In this exercise, you will complete the following tasks:

- Task 1: Create a semantic model and turn on Q&A
- Task 2: Generate a report and insights with Copilot for Power BI

## Task 1: Create a semantic model and turn on Q&A

In this task, you create a semantic model from the **website_bounce_rate** table and enable natural language Q&A on it.

1. In Microsoft Fabric, select **Workspaces**, select the **<inject key="Fabric Workspace Name" enableCopy="false"/>** workspace, and then select the **ZavaLakehouse** lakehouse.

1. In the lakehouse view, select **New semantic model**.

    ![New semantic model](./media/new-semantic-model.png)

1. In the **New semantic model** dialog, enter the following name:

    - **Name:** `website_bounce_rate_model`

    Search for `website_bounce_rate` in the **Tables** section, select it, and then select **Confirm**.

    ![Website bounce rate model](./media/website-bounce-rate-model.png)

1. In the top bar, select the **Settings** (gear) icon, and then select **Power BI settings**.

    ![Settings pane](./media/fabric-settings-pane.png)

1. Select the **Semantic models** tab, and then select **website_bounce_rate_model** in the left pane. Scroll down and expand **Q&A**, select the **Turn on Q&A to ask natural language questions about your data** checkbox, and then select **Apply**.

    ![Turn on Q&A](./media/website-bounce-rate-model-qa.png)

## Task 2: Generate a report and insights with Copilot for Power BI

In this task, you see how Copilot for Power BI, together with Direct Lake mode, helps Wendy build a report and get insights without writing code.

1. In the left navigation pane, select the **website_bounce_rate_model** semantic model to open its details.

1. Select **File**, and then select **Create a new report**.

    ![Create a new report](./media/website-bounce-rate-model-report.png)

1. Select the **Copilot** icon in the top menu bar to open the **Copilot** pane. To make more room on the report canvas, collapse the **Filters**, **Visualizations**, and **Data** panes.

1. In the **Copilot** pane, turn on the **Preview** toggle, and then select **Get started**.

1. In the Copilot chat box, enter the following prompt and select **Send**. Copilot describes what the dataset contains.

    ```
    What's in my data?
    ```

    ![What's in my data](./media/whats-in-my-data.png)

1. Enter the following prompt and select **Send**. Copilot generates a report page with relevant visuals.

    ```
    Create a detailed page to analyze the Website Bounce Rate
    ```

    ![Report generated by Copilot](./media/copilot-report.png)

    > **Note:** If you see **Something went wrong**, refresh the page and repeat this step. The service can be busy at times.
    >
    > - If Copilot needs more context, rephrase your prompt with more detail.
    > - Copilot's responses won't match the screenshots exactly, but the outcome will be similar.

    The report shows that Zava's website bounce rate is especially high in the **Millennials** customer segment. Next, ask Copilot how to improve it.

1. Enter the following prompt and select **Send**:

    ```
    Based on the data in the page, what can be done to improve the bounce rate of millennials?
    ```

1. Review Copilot's suggestions. Wendy concludes that Zava needs to transform its mobile website experience for millennials, which should also reduce millennial customer churn.

    ![Copilot suggestions](./media/copilot-suggestions.png)

1. Zava's leadership team also wants a quick summary of the whole report. In the **Visualizations** pane, select the **Narrative** visual to add it to the report canvas.

    ![Narrative visual](./media/narrative-visual.png)

1. Resize the **Narrative** visual to fit the canvas. You can replace one or two of the existing visuals with it.

1. In the visual, select **Copilot (preview)**. Enter the following prompt, and then select **Update**:

    ```
    Summarize the data, provide an executive summary, indicating important takeaways
    ```

    ![Update the Narrative visual](./media/narrative-update.png)

1. Select **Close (X)** to close the Narrative pop-up window.

    ![Close the Narrative pop-up](./media/narrative-close.png)

    > **Note:** The summary updates automatically when you filter the report, and Copilot can write it in another language if you ask.

1. Select **File**, and then select **Save**. Enter the following name, and then select **Save**:

    - **Name:** `Website Bounce Rate Report`
